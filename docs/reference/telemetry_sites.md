# Victorian traffic monitoring site reference data

Reference information for the monitoring locations used in the traffic
dataset. Contains site identifiers, location descriptions and geographic
coordinates.

## Usage

``` r
data(telemetry_sites)
```

## Format

A data frame with 55 rows and 4 columns:

- site:

  Monitoring site identifier.

- site_description:

  Description of the monitoring location.

- latitude:

  Latitude of the monitoring location.

- longitude:

  Longitude of the monitoring location.

## Source

Victorian Department of Transport, Telemetry Traffic Counts and
Classification dataset.
